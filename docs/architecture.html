Coverage Gap POC Map

The tool finds test cases that should exist in Zephyr Scale but don't. It derives expected scenarios from Jira stories and from the source code, matches them by meaning against existing Zephyr cases, and writes an Excel workbook plus summary.md. Nothing is written to Zephyr until you approve a gap.

How a run flows

scripts/agents.mjs walks six stages left to right. For each one it runs the stage script, then starts that stage's agent to review the result. An agent never edits state directly; it writes a review file that the next stage merges.

Before the agents: /coverage in your session

The slash command decides what gets analysed before the chain starts. This part runs in your interactive Claude session because headless agents can't use the claude.ai Rovo connector.

Where to make a change

Project facts live only in profiles/<name>/; everything under scripts/ stays project-agnostic.

A module's keywords, folder or stories

profiles/avl/modules.json, or vocab.mjs --save

Models, batch sizes, byte caps, token budget

config/run.json (models, batch, limits, claude.maxTokensPerRun, agents.model)

What an LLM stage asks or returns

prompts/<stage>.md and the schema source, then node scripts/gen-llm-schemas.mjs. Only that stage's cache is invalidated.

An agent's instructions

.claude/agents/<name>.md. Keep StructuredOutput in its tool list.

What an agent is allowed to run

allowedTools() in scripts/agents.mjs. Own stage only, read-only Zephyr tools.

What an agent can change

schema/review/<key>.schema.json and the merge in scripts/lib/reviews.mjs

Which stories count as testable

scripts/lib/triage-rules.mjs and jira.nonTestable in the profile

Which Zephyr cases get compared

scripts/lib/candidates.mjs, limits.candidateCasesPerStory

Which code is read

code.mjs, discover.mjs, code.discovery in config. Preview with code-map.mjs at 0 tokens.

Workbook sheets or summary text

scripts/lib/workbook.mjs, scripts/lib/report.mjs

Creating cases in Zephyr

scripts/create-approved.mjs, zephyr_mcp/

Any new pure helper

Add a test in test/core.test.mjs, run npm test

Rules a change must keep

  • Zephyr has no delete endpoint. Cases are created only through create-approved (dry run, then --yes) after explicit approval.
  • No Jira comments or issue changes during an analysis.
  • Agents change state only through review/<key>.json, never state.json or the workbook.
  • Report tokens only, never cost; a test enforces it. Every decision row carries a reasoning string.
  • cache/<profile>/repos/ are read-only reference clones.
